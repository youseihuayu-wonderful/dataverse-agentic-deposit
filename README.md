# Dataverse Agentic Deposit — public design notes

Public tracking repo for the design proposal:

**Human-in-the-Loop Agentic Deposit Assistance for Dataverse**

- Full proposal: [`dataverse_agentic_deposit_proposal.md`](./dataverse_agentic_deposit_proposal.md)
- Upstream pyDataverse Feature Request (Layer 1 validation): to be linked after issue creation

## Layers

1. **Layer 1** — Deterministic metadata validation in **pyDataverse** (no AI). Tracked as a Feature Request on [gdcc/pyDataverse](https://github.com/gdcc/pyDataverse).
2. **Layer 2** — Guided deposit assistant as a Dataverse External Tool (human-in-the-loop agents). Discussed in the proposal; not a pyDataverse core change.

Issues in this repo are for design discussion and work tracking around the full proposal.
